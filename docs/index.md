# Avisi Cloud Provider

The `acloud` provider manages resources on the [Avisi Cloud Platform](https://avisi.cloud): environments,
[Avisi Managed Environments (AME)](https://docs.avisi.cloud/docs/product/why-ame) Kubernetes clusters, node pools,
cloud accounts and maintenance schedules. Data sources look up what already exists, such as cloud accounts,
regions, node types and update channels.

For a ready-made cluster with node pools, see the
[`avisi-cloud/cluster/acloud`](https://registry.terraform.io/modules/avisi-cloud/cluster/acloud/latest) and
[`avisi-cloud/nodepool/acloud`](https://registry.terraform.io/modules/avisi-cloud/nodepool/acloud/latest) modules,
which are built on this provider.

## Example Usage

```terraform
terraform {
  required_providers {
    acloud = {
      source  = "avisi-cloud/acloud"
      version = ">= 0.12.0"
    }
  }
}

# The token can also come from ACLOUD_PERSONAL_ACCESS_TOKEN, so it never has to be in a .tf file.
provider "acloud" {
  token        = var.acloud_token
  organisation = "example-org" # used by every resource and data source that doesn't set its own
}

variable "acloud_token" {
  description = "Avisi Cloud Personal Access Token. Create one under API Access in the Console."
  type        = string
  sensitive   = true
}
```

## Authentication

The provider logs in with a
[Personal Access Token](https://docs.avisi.cloud/docs/product/tasks/how-to/personal-access-tokens).
Every setting can also come from an environment variable, so no secret has to be in a `.tf` file:

| Setting | Environment variable | Default |
| --- | --- | --- |
| `token` | `ACLOUD_PERSONAL_ACCESS_TOKEN` | required |
| `acloud_api` | `ACLOUD_API_ENDPOINT` | `https://api.avisi.cloud` |
| `organisation` | `ACLOUD_ORGANISATION` | none: set it here or on each resource |

The organisation slug is shown on the Settings page in the [Console](https://console.avisi.cloud/).

## Schema

### Required

- `token` (String, Sensitive) Personal Access Token for the Avisi Cloud API. Can also be set with the `ACLOUD_PERSONAL_ACCESS_TOKEN` environment variable.

### Optional

- `acloud_api` (String, Sensitive) Base URL of the Avisi Cloud API. Can also be set with the `ACLOUD_API_ENDPOINT` environment variable. Defaults to `https://api.avisi.cloud`.
- `organisation` (String) Slug of the Organisation used when a resource or data source does not set `organisation`. Can also be set with the `ACLOUD_ORGANISATION` environment variable.
