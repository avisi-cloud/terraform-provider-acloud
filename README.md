# Terraform Provider Acloud

Avisi Cloud Platform Terraform Provider for managing your Avisi Cloud resources using Infrastructure as Code practices.

## Documentation

- [registry.terraform.io/providers/avisi-cloud/acloud/latest/docs](https://registry.terraform.io/providers/avisi-cloud/acloud/latest/docs)

## Requirements

- [Terraform](https://developer.hashicorp.com/terraform/install)
- [Go](https://go.dev/doc/install) to build the provider or contribute. The required version is defined by the `go` and `toolchain` directives in [go.mod](go.mod).

## Contributing

Build and install the provider locally. `OS_ARCH` defaults to the platform of your Go toolchain (for example `darwin_arm64`); override it if needed:
```bash
make install NAMESPACE=local HOSTNAME=terraform.local
```

Use the locally installed provider in your Terraform configuration:
```hcl
terraform {
  required_providers {
    acloud = {
      source = "terraform.local/local/acloud"
    }
  }
}
```

## Testing

The most common checks are available as `make` targets. CI runs the same targets on every pull request.

| Command | Description |
|---------|-------------|
| `make test` | Unit tests (`go test ./...`). Acceptance tests are always skipped, even if `TF_ACC` is set in your shell. |
| `make testrace` | Unit tests with the race detector. |
| `make vet` | `go vet ./...` |
| `make fmtcheck` / `make fmt` | Check or apply `gofmt` formatting. |
| `make tidycheck` | Verify `go.mod` and `go.sum` are tidy (run `go mod tidy` to fix). |
| `make vulncheck` | Scan reachable code for known vulnerabilities with a pinned `govulncheck`. |
| `make check` | All of the above. |

Unit tests must not need credentials or reach the Avisi Cloud API: use fake API clients or local HTTP fixtures instead.

`make testacc` runs Terraform acceptance tests (`TF_ACC=1`), if any exist. These create and destroy **real** Avisi Cloud resources and need credentials through `ACLOUD_PERSONAL_ACCESS_TOKEN`, `ACLOUD_ORGANISATION` and optionally `ACLOUD_API_ENDPOINT`. Only run them against an organisation intended for testing.
